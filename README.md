# jamesh-gh

## About

I'm a developer with a professional background in data engineering and an interest in web applications and AI. I build and support data pipelines using SQL Server, T-SQL, SSIS, Python and Airflow. My personal projects give me a way to apply that experience to software people interact with and to understand how AI agents work.

## Selected projects

- **Feedback Desk.** A React and TypeScript prototype for reviewing fictional service feedback. Users can filter entries, open a record and save a review note for the session.
- **A&E Waiting Times Agent.** A Python command-line demo that uses tool calls to look up fictional waiting-times data. It prints each tool request and result.

## Current focus

- Building web applications with React, TypeScript and C#.
- Exploring how AI agents use tools and how to evaluate their behaviour.
